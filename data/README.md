# ローカルデータの保存先

このディレクトリーは、このREADMEを除いてGit対象外です。実行時に必要な保存先を作成します。

| ディレクトリー | 内容 |
|---|---|
| `bags/` | 元のMCAP、映像・関節状態・指令、Episode情報 |
| `collections/` | 収集セッション、採用可否、Runtimeログ |
| `datasets/` | 学習用に変換したDataset |
| `reviews/` | 確認用HTML・画像・動画 |
| `models/` | 学習済みモデルと登録情報 |
| `envs/` | 追加モデル用Python環境と取得した依存ソース |
| `calibration/` | 校正変更のバックアップ |
| `backups/` | ローカル設定・ソースの控え |
| `logs/` | 学習・診断・評価・試験の出力 |
| `run/` | 実行中プロセスの管理情報 |

`reviews/` は確認用、学習には `datasets/` を使います。元の記録を削除すると再変換できなくなるため、バックアップ方針に従って管理してください。

データや重みを別途配布する場合は、その公開範囲・利用条件を確認し、専用の配布先を用意します。通常のソース公開には含めません。
